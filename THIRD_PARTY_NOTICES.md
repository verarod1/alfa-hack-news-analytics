# Сторонние компоненты и состояние интеграций

## Реально используются

Backend: Python 3.11, FastAPI, Uvicorn, Pydantic/Pydantic Settings, psycopg,
python-dotenv; PostgreSQL 16. Версии Python-пакетов закреплены в
backend/requirements.txt и backend/requirements.lock.
Тесты: unittest стандартной библиотеки, TestClient/HTTPX2; dev-версии — в requirements-dev.txt.
Frontend остаётся React/TypeScript/Vite; версии — frontend/package-lock.json.
Docker-образы указаны в Dockerfiles и Compose; закрепление image digest оставлено оператору.

## Данные и тестовые интеграции

Исходные обезличенные CSV Альфа-Банка читаются локально и не включаются в текущие
изменения Git. Их публикация допускается организаторами только в приватном репозитории
с доступом команды и жюри alfa-hack-2026; приватность нужно подтвердить отдельно.
Seed содержит три явно синтетические новости без вымышленных ссылок реальных СМИ.
ml_test_adapter используется только интеграционными тестами и не является настоящей
моделью/источником аналитики; подключать его для демонстрации AI-функций нельзя.

## Подготовлено, но ещё не подключено

Интерфейс адаптера ML, хранение оценок, проверка локального манифеста аналитических
материалов банка. LLM/RAG, внешний сбор новостей и алгоритм ранжирования не реализованы.
Pandas, NetworkX, BeautifulSoup4 и Feedparser присутствуют в зависимостях проекта,
но текущая Backend-логика не использует их для графового/новостного/AI-пайплайна.

Генеративные модели после интеграции — только разрешённые кейсом Gemma 4 26B A4B,
GLM-5.3-Flash, Qwen3.6 35B A3B, DeepSeek-V4.1-Flash, Qwen3-VL-30B-A3B-Instruct,
Kimi-K2.6. Ни одна не вызывалась при разработке/тестировании Backend.
Конкретные API model IDs и активный выбор согласуются с ML-разработчицей.
Для embeddings/rerankers по официальному вебинару ограничение этого списка не применяется;
такие компоненты здесь пока не подключены.
