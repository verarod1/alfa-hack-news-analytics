# Сторонние компоненты, данные и интеграции

Актуализировано по исходникам 26.10.2026. Это перечень использования, не заключение о лицензировании. Точные версии Python: backend/requirements.txt и requirements.lock; JavaScript: frontend/package-lock.json. Лицензии и notices поставщиков сохраняются в установленных дистрибутивах; перед распространением образов требуется проверить условия всех транзитивных зависимостей.

## Программные компоненты

- Python 3.11, FastAPI, Uvicorn, Pydantic/Pydantic Settings, python-dotenv: API и конфигурация.
- PostgreSQL 16, psycopg/binary: хранение и SQL.
- React, React DOM, TypeScript, Vite, plugin-react: интерфейс и сборка; oxlint: статическая проверка.
- nginx: раздача frontend и proxy API; Docker/Compose: упаковка и запуск.
- requests, truststore, BeautifulSoup4, feedparser: HTTP, сертификаты и сбор публикаций.
- pandas, NetworkX присутствуют в наборе зависимостей; их наличие не означает отдельную графовую ML-модель.
- OpenAI Python SDK: клиент совместимого API внешнего провайдера, не свидетельство использования моделей OpenAI.
- ChromaDB, sentence-transformers, PyTorch CPU: локальный векторный поиск и embeddings.
- PyMuPDF и pypdf: PDF; условия распространения PyMuPDF следует отдельно проверить перед публикацией образа.
- unittest, HTTPX2/TestClient: тесты.

Базовые образы перечислены в Dockerfiles и Compose, пока без digest. Полная транзитивная ведомость определяется lock-файлами.

## Модели и сервисы

team_ml.adapter реализует анализ и чат; ранжирование и RAG также реализованы. Активная модель задаётся LLM_MODEL, специальные операции — LLM_RANK_MODEL/LLM_CHAT_MODEL/LLM_OCR_MODEL. По умолчанию настроено имя Gemma-4-26B-A4B, OCR — Qwen3-VL-30B-A3B-Instruct. Это конфигурация, не подтверждение доступности или проверки провайдера. Разрешённые идентификаторы проверяются в backend/app/services/ml_gateway.py. Endpoint и ключ предоставляются отдельно.

Embedding-модель по умолчанию: intfloat/multilingual-e5-small. Её веса не включены в Git, revision не закреплён. Загрузка и кэш требуют доступного места и соответствующих условий использования модели. OCR может передавать страницы внешнему провайдеру.

## Данные и имитации

- Исходные CSV хакатона доступны только локально, не публикуются этим комплектом.
- backend/fixtures/review.sql: полностью искусственные три компании, платежи, связи и новости; совпадение ID с демо нужно только для маршрутов UI. Это не реальные показатели компаний.
- backend/scripts/seed_demo_news.py: отдельные синтетические новости.
- backend/fixtures/official_news.json: сохранённые реальные публикации со своими источниками, не гарантия доступности live RSS.
- RSS-коннекторы: ЦБ, Правительство, Минфин, ФНС, Интерфакс, Финмаркет; доступность зависит от сети, конфигурации и сайта. Подробности: docs/NEWS_COLLECTOR.md.
- PDF банка пользователь предоставляет отдельно; в Git они не включены. Цитаты должны ссылаться на подтверждённый документ и страницу.
- backend/tests/ml_test_adapter.py и ml_pipeline_test_adapter.py: контролируемые имитации для тестирования. compose.review.yml использует первый только для явно синтетической технической проверки. Его ответы не являются результатом реальной модели.
- frontend/src/mocks: локальные заготовки интерфейса, не источник реальной аналитики.

В проверочном Compose отсутствуют реальные LLM-вызовы и сбор RSS. В обычном Compose они зависят от настройки; отсутствие ключа нельзя интерпретировать как успешную AI-интеграцию.
