Текст выделен из официальных страниц; даты сверены с сохранённой проверкой
официального RSS от 24.10.2026. Первая страница использована из уже полученного
локального снимка, вторая получена с соблюдением robots. Архивные публикации
не выдаются за свежую новость сегодняшнего дня. Минфин не заменён текстом СМИ
или придуманными публикациями.

```bash
python backend/scripts/import_news_fixtures.py --dry-run
python backend/scripts/import_news_fixtures.py
```

Скрипт не обращается в интернет/ML, проверяет весь JSON до записи,
использует NewsInput и news_service.save_news, показывает конфликты без перезаписи.
Повторный импорт возвращает существующие ID. Все записи видны через
`GET /api/v1/news/{news_id}` и `GET /api/v1/feed` — отдельного GET `/news` в контракте нет.

## Демо

Настройки по умолчанию: `DEMO_COMPANY_IDS=U_44564,U_19717,U_9250`.
Каждая компания найдена в CSV и существующей PostgreSQL, одна запись, CLIENT.
Проверены отрасли, исходные финансовые поля, банковские продукты, платёжные
контрагенты, групповые связи и отсутствие общих физлиц в полученной выборке.
Исходные таблицы не изменялись; приблизительные суммы в код не записывались.

`GET /api/v1/demo-profiles` даёт 6 вариантов: три компании × CEO/CFO.
При переключении передавайте `X-Company-ID` той же компании, что company_id в запросе.
Старый `.env` может переопределять defaults: он не редактировался автоматически.
Новости общие для всех компаний, персонализация идёт через существующие ML-оценки.
Без оплаченного запуска ML лента остаётся chronological/null, без вымышленных оценок.
