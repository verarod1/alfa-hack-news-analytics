# Архитектура решения: Новостная аналитика Альфа-Банка

## 1. Общая структура (High-Level Architecture)
Проект представляет собой монорепозиторий, разделенный на микросервисы, запускаемые через единый Docker Compose.

### Компоненты:
* **Frontend (React + TypeScript):** Веб-интерфейс, симулирующий интеграцию в интернет-банк Альфа-Бизнес. Отвечает за визуализацию персонализированной новостной ленты и отображение бизнес-инсайтов.
* **Backend API (Python / FastAPI):** Точка входа для фронтенда. Обрабатывает запросы, управляет состоянием и запускает AI-агентов.
* **Data Services & Parsers:** Изолированные модули для обработки графа компаний (`df_Uid_data_hack.csv`, `df_Fid_Uid_link_hack.csv`) и парсинга внешних новостей.
* **AI Agent Pipeline:** Ядро системы, реализующее многошаговую агентную логику обработки информации.

## 2. Агентная логика (ReAct Architecture)
В соответствии с требованиями кейса, система не использует внешние готовые сервисы, а реализует собственный цикл рассуждений (Reasoning + Acting)[cite: 15, 26]:
1. **Планирование (Planning):** LLM анализирует входящую новость и формирует план проверки влияния события на конкретную компанию[cite: 15].
2. **Использование инструментов (Tool Use):** Агент обращается к локальному RAG (аналитика Альфа-Банка) или сервису профилирования клиента для обогащения контекста[cite: 15, 21].
3. **Обмен данными:** Состояние агента и промежуточные выводы передаются между шагами строго через типизированные JSON-схемы[cite: 21].
4. **Рефлексия (Reflection):** Финальная самопроверка сгенерированного вывода на отсутствие галлюцинаций, полноту интерпретации (риски/возможности) и корректную ссылку на позицию банка[cite: 15, 17].

## 3. Поток данных (Data Flow)
1. Модуль парсинга собирает новостной поток.
2. Быстрая модель (например, Gemma 4 26B) фильтрует инфошум и извлекает сущности[cite: 26].
3. Бэкенд сопоставляет сущности с бизнес-контекстом клиента (ОКВЭД, транзакции, возраст компании)[cite: 14, 23].
4. Основной AI-оркестратор (GLM-5.3-Flash / DeepSeek) формирует персонализированный инсайт[cite: 14, 26].
5. Результат отдается по REST API на клиентскую часть.
