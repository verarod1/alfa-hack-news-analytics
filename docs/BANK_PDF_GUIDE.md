# Как добавить подтверждённые материалы Альфа-Банка

Код для индексации уже подготовлен. От вас нужны только сами PDF и решение, какие из них разрешено показывать в демонстрации. Сообщения Банка России, ФНС и других организаций не подходят для блока материалов Альфа-Банка.

## 1. Выберите документы

Возьмите PDF, опубликованные Альфа-Банком или одобренные командой банка для этого кейса. В документе должна быть содержательная позиция по нужной теме, а не просто логотип банка. Для новости о ключевой ставке нужен материал банка о ставке или условиях финансирования; документ ЦБ не заменяет его. Для других новостей подходящего материала может не быть — тогда пустой блок является корректным результатом.

Сохраните название, дату и исходную ссылку каждого документа в отдельном списке для проверки. Перед показом пользователям убедитесь, что публикация и цитирование разрешены.

## 2. Положите PDF в проект

Скопируйте файлы в `data/raw/bank_analytics/` внутри проекта. Если папки нет, создайте её. Файлы остаются локальными и не должны попадать в Git. Текстовые PDF индексируются без OCR; сканы требуют отдельного распознавания.

## 3. Запустите подготовку

Откройте PowerShell в корне проекта при работающем Docker Compose и выполните:

```powershell
.\scripts\prepare_bank_pdfs.ps1
```

Скрипт проверит наличие PDF, запустит индексатор внутри backend-контейнера и проверит непустой `data/ocr_cache/bank_materials.json`. В ответе должно быть `документов в манифесте` больше нуля. Первичная индексация может скачивать модель эмбеддингов и занимать время.

Если скрипт сообщает о `BANK_MATERIALS_PATH`, в текущем окружении задан другой манифест через `DOCKER_BANK_MATERIALS_PATH`. Уберите эту настройку и пересоздайте backend: `docker compose up -d --force-recreate backend analysis-worker`, затем повторите подготовку PDF.

Если скрипт сообщает о PDF без распознанных страниц, проверьте, что это сканы. После решения о расходовании бюджета на OCR выполните:

```powershell
.\scripts\prepare_bank_pdfs.ps1 -AllowOcr
```

OCR не включается автоматически. Если PowerShell запрещает запуск локальных скриптов, используйте команду индексатора напрямую: `docker compose exec backend python -m app.services.rag --limit 100`.

## 4. Пересчитайте нужные новости

Откройте `http://localhost:3000/demo`, выберите компанию и роль, откройте нужную новость и нажмите **«Пересчитать разбор»**. Новый разбор использует текущие материалы банка и расходует один ML-запрос. Старые завершённые разборы не меняются автоматически. Повторите только для тех сочетаний компании, роли и новости, которым новый документ действительно относится.

## 5. Проверьте результат

В блоке **«Материалы Альфа-Банка по теме»** проверьте текст, документ, номер страницы и дословную цитату. Система должна отклонить цитату, которой нет на указанной странице. Если подходящий фрагмент не найден, останется сообщение об отсутствии подтверждённых материалов. Это лучше, чем выдавать вывод модели или новость другого ведомства за позицию банка.

Сейчас локальные PDF не открываются по ссылке из интерфейса: в результате доступны название документа, страница и цитата. Если для демонстрации нужна кликабельная ссылка, передайте публичные адреса одобренных документов — их можно подключить отдельно без публикации локальных файлов.
